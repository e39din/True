Делаем язык программирования True и его интерпретатор Simple

Описание языка:

Программу называем циклом (cycle)
Файл с расширением .cycle интерпретируется интерпретатором Simple (интерфейс состоит из ряда циклов\программ на True)

В файле расположен текст разделенный символом \n на линии\строки\кубиты(синонимы далее)
Нумерация линий по порядку начинается с 1-цы

Каждая линия - кубит данных, которая воспринмается определителм данных
кубит данных может иметь разные значения для разных наблюдателей, определителей данных

Определитель данных - тот кто определяет как воспринимать данные
Пока что в языке добавлен только один тип определителя данных - агент (agent)

Определители данных и агенты в частности являются частью файла цикла
Агент показывается на старте цикла как первая линия в виде: 
"Mr.Green, #00ff00 | Data as <type> | Aim: <condition>"
Там указывается имя агента, цвет подсветки, строка уазывающая "тип восприятия"\тип определения линии\кубита ниже агента, далее указано условие исполненной цели, если условие истинно то агент прекращает движение по циклу и возвращается на первую строку цикла (в условии могут использоваться любые имена что доступны в ленте циклов)

Строка подсвечивается цветом указанным в линии агента

Агент может воспринимать кубиты\линии такими типами:
separator: ""
container: "any string" - значение\содержимое контейнера
named container: "any string = containerName" - слева от "=" значение\содержимое контейнера, справа от "=" название контейнера
(можно именовать несколькими именами они будут синонимами: 123 = name, surname)
action: "any string with container\containers names => containerName" 
action: "any string = containerName" 
(именованное действие можно подставлять по имени, т.е. агент встречая имя действия работает с содержимым контейнера как с действием)

действия\actions могут быть таких видов:
a => b - копирование значения левого конртейнера в правый контейнер
a -> b - перемещение значения левого конртейнера в правый контейнер
a =>| b:axis - вставка-копированием значения левого конртейнера в ось правого контейнера
a ->| b:axis - вставка-перемещением значения левого конртейнера в ось правого контейнера
a <-> b -  swap, обмен местами значений контейнеров
^ b - прыжок агента к именованному контейнеру, по имени контейнера
^ 1 - прыжок агента на линию с указанным порядковым номером
^ :cycleName:1 , ^ :cycleName:b - прыжок с явным указанием названия цикла (добавление других циклов описано ниже)

(прыжок может осуществляться как выше по тексту так и ниже)
(если ось не указана при вставке по умолчанию вставляется по оси x)
(можно совершать операцию копирования и копирования-вставки значений сразу для нескольких контейнеров все они получат одинаковое значение: 123 => a, b, c )
(можно делать цепочку действий: 123 => a =>| b -> c ^ a)

при:
abc = a
= b

Действие может начинаться с вопроса, с условия: a != b ? a => b - действие справа от вопроса выполнится если сработает условие что слева от вопроса

при распознавании типа кубита\линии агент маркирует\считает все остальные линии ниже до разделителя(тип separator) или конца файла, как линии того же типа, пример:

Mr.Green, #00ff00 | Data as <type> | Aim: <condition>
123 = name
456
789

агент распознал именованный контейнер с именем = name, агент считает что значение контейнера name - 123\n456\789

еще пример:
Mr.Green, #00ff00 | Data as <type> | Aim: <condition>
a == finish ? 
123456 => b
asdsa => c
c + 1 => ::math => result
здесь агент распознал первую строку как действие с условием, и при сработке условия выполнит все действия ниже до разделителя, включая другие действия с условиями

еще пример:
Mr.Green, #00ff00 | Data as <type> | Aim: <condition>
Просто какой-то текст
Поисание операции => ::math
Комментарий

здесь агент считает что все линии ниже до разделителя имеют тип неименованного контейнера, т.е. литералы, даже если там встретятся операции и действия

еще пример:
Mr.Green, #00ff00 | Data as <type> | Aim: <condition>
a + b => ::math = func1
::math => result

здесь агент считает что значение именованного контейнера такое: a + b => ::math\n::math => result, соответственно при встрече далее имени func1 агент исполнит блок действий одно за другим

Ключевое здесь - мы работаем с кубитами, определяем один - определяются сразу все остальные ниже по цепочке

К названию контейнера при использовании может подставить ось x, y, с осью работаем как со списком\массивом, строкой разделенной символами, нумерация содержимого начинается с единицы
По умолчанию ось x - символы строки по горизонтали
По умолчанию ось y - линии разделенные \n по вертикали
Разделитель оси можно переопределить так:
array:x(, ) - в скобках указывается строка или символ разделитель

можно получать данные по порядковому номеру из оси: list:x:i
можно устанавливать данные в ось по порядковому номеру: 42 => list:x:i
можно вставлять данные в ось по порядковому номеру, остальное содержимое сдвигается: 6 =>| list:x:i

Пример:
123 = list
= n
list:x:2 -> n
после операции в list останется 13 в n будет 2


у интерпретатора есть поле ввода для ввода паузы после шага в миллисекундах, по умолчанию стоит 390, можно установить в 0 - тогда паузы не будет

у интерпретатора 1 кнопка-иконка с двумя состояниями: play, pause
При нажатии pause выполнение останавливается на текущем месте
При повторном нажатии play выполнение возобновляется


При проигрывании цикла интерпретатор шаг за шагом перемещает линию агента все ниже и ниже меняя его местами с линией под ним

На каждом шаге меняется тип восприятия обрабатываемой линии в строке агента
На каждом шаге агент взаимодействует с линией исходя из ее типа

separator: ничего не делает
container: ничего не делает
named container: считывает значение и запоминает
action: выполняет действие, подставляет запомненые значения вместо имен при выполнении действия
(после выполнения действия UI обновляется, все изменения в тексте, изменения данных должны быть отображены, мы на лету меняем код цикла)
(если данные изменились после действия, обновить значения запомненных данных по имени измененного контейнера)

в интерпретаторе добавить кнопку + по которой будем добавлять текстовый редактор и файл-цикла ниже, у каждого редакторо отображать имя файла и добавить возможность редактирования, все файлы сохраняются в текущей папке

новый цикл добавляется ниже под предыдущим, лента циклов может прокручиваться

к каждому циклу в ленте у нас есть доступ через операцию прыжка: ^ :cycleName:1
т.е. туда перемещается агент который исполняет действие

Для использования расширений, сторонних функций, библиотек, скомпилированных программ используем синтаксис: ::function

Например сделаем функцию math, которая будет высчитывать математические выражения переданные ей:
1 + 4 => ::math - функция высчитала выражение и хранит значение, как контейнер, т.е. на каждую функцию-расширение заводится свой контейнер с результатом
получить резултат можно так например:
= result
::math => result

в ::math есть основные мат.операции, + - * \ % \^ == != && || (в ответ на булевы операции вернется 1 или 0)

символы операций можно превращать в литералы так: \^ \=> \->| ,  так же как и имена: \name \::math
